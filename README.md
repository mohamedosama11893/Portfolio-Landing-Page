# Portfolio Landing Page 🚀

A fully responsive landing page built as part of my front-end development learning journey.  
This project focuses on clean structure, modern layouts, and responsive design across all devices.

---

## 📌 Project Overview

The **Portfolio Landing Page** is a static website that demonstrates how to build a modern, responsive layout using pure front-end technologies without any JavaScript frameworks.

The main goal of this project was to improve my understanding of:
- Layout building
- Responsive design principles
- Writing clean, maintainable CSS
- Changing theme color

---

## 🛠 Technologies Used

- **HTML5** – Semantic and well-structured markup  
- **CSS3** – Styling and layout design  
- **Flexbox** – Flexible layouts and alignment  
- **CSS Grid** – Complex and responsive page structures  
- **SASS (SCSS)** – Better CSS organization, variables, and reusability  

---

## ✨ Features

- Fully responsive design (Desktop, Tablet, Mobile)
- Clean and semantic HTML structure
- Modern layout using Flexbox & CSS Grid
- Reusable components
- Organized and scalable CSS architecture
- Smooth hover effects and simple animations
